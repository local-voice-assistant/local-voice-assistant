隐私说明

# 本地语音助手隐私说明

生效日期：2026-10-25

## 我们收集什么

默认情况下，**我们不运营云端账号，也不收集你的录音或转写内容**。

数据保存在你的电脑上：

- 应用数据目录：`~/Library/Application Support/本地语音助手/`
- 包括：设置、会话元数据、本机下载的识别模型、加密后的 API Key（若你配置了云端模型）

## 音频与转写

- 会议录音、听写音频与转写结果默认只在本机处理与存储。
- 不会自动上传到我们的服务器（本项目当前无此类服务器）。

## 可选云端模型

若你在设置中填写了第三方大模型的 API Key 与地址：

- 相关**文本**（如旁听洞察、总结请求）会发往你配置的服务商；
- API Key 以加密形式保存在本机；请勿把密钥分享给他人；
- 第三方服务商的数据处理按其隐私政策执行。

## 模型下载

首次使用可从公开模型源（如 GitHub / 国内镜像）下载开源识别模型。下载过程仅获取模型权重，不上传你的个人内容。

## 诊断包

「导出诊断包」会生成脱敏日志与运行信息，**不含录音、转写正文或 API Key**。仅在你主动导出并发送时才会离开本机。

## 更新检查

若开启检查更新，应用会请求官网的 `latest.json`（仅版本号与下载信息），不附带个人标识。

## 联系

https://github.com/local-voice-assistant/local-voice-assistant/issues

| 组件 | 许可（典型） | 说明 |
|------|--------------|------|
| Node.js | MIT 等 | 运行时 |
| sherpa-onnx / sherpa-onnx-node | Apache-2.0 | 本机 ASR / VAD / 声纹 / 标点 |
| @earendil-works/pi-coding-agent | 按其仓库许可 | Agent 运行时 |
