# 本地语音助手

本地优先的 macOS 实时转写、系统听写与 AI 助手。音频默认不出本机；需要时再接入你自己的云端模型。

**当前版本**：0.1.0（预发布）· Apple Silicon · macOS 14.2+

> 本仓库仅托管**产品说明、发行说明与安装包**，**不包含源代码**。独立产品网站将在后续再发布。
