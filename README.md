## 扩展硬件

支持通过蓝牙连接 **CB08 录音卡** 与 **AI Passport 电子工牌**，作为随身音源与会议控制。

详见 **[扩展硬件详情](HARDWARE.md)**（两款设备分别介绍）。

---

## 本地优先

- 识别、说话人区分与听写**默认在本机完成**
- 仅当你主动配置云端大模型 API 时，相关文本才会发往你选择的服务商
- 数据目录：`~/Library/Application Support/本地语音助手/`
