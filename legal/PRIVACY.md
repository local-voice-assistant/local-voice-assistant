# 本地语音助手隐私说明

生效日期：2026-10-29

## 我们收集什么

默认情况下，**我们不运营云端账号，也不收集你的录音或转写内容**。

数据保存在你的电脑上：

- 应用数据目录：`~/Library/Application Support/本地语音助手/`
- 包括：设置、会话元数据、本机下载的识别模型、加密后的 API Key（若你配置了云端模型）

## 音频与转写

- 会议录音、听写音频与转写结果默认只在本机处理与存储。
- 录音和转写内容不会上传。匿名使用统计见下文，可随时关闭。

## 可选云端模型

若你在设置中填写了第三方大模型的 API Key 与地址：

- 相关**文本**（如旁听洞察、总结请求）会发往你配置的服务商；
- API Key 以加密形式保存在本机；请勿把密钥分享给他人；
- 第三方服务商的数据处理按其隐私政策执行。

## 模型下载

首次使用可从公开模型源（如 GitHub / 国内镜像）下载开源识别模型。下载过程仅获取模型权重，不上传你的个人内容。

## 匿名使用统计

默认开启。应用会向我们自己的统计服务发送一条很小的状态：

- 是否安装并启动过
- 是否下载了语音模型
- 是否配置了云端模型
- 是否成功听写过
- 是否成功转写过
- 辅助功能是否已确认授权（不会为此弹出授权框）
- 麦克风是否已实际采集成功（不会为了统计去申请麦克风）
- 蓝牙是否处于可用
- 转写来自实时会议、录音卡文件，或两者都有
- 听写写入系统光标、应用内，或两者都有
- macOS 主版本号（例如 15、26）
- 识别语言：中文、英文或自动
- 应用版本、操作系统和架构

用一个随机编号区分不同安装，它不是设备指纹。不包含录音、转写文字、文件路径、API Key、设备序列号或姓名。服务不把 IP 写入数据库或日志。

可在「设置 → 关于 → 匿名使用统计」关闭。关闭后不再发送。

## 更新检查

若开启检查更新，应用会请求公开仓库中的 `latest.json`（仅版本号与下载信息），不附带个人标识。
